## 三、发现 1：终端价值 θ 必须保留（θ 消融，最确定）

同情景、同随机种子，只差 θ：

| | 删 θ（跨日近视） | 含 θ |
| --- | ---: | ---: |
| M3 总费用 | 2062.3 万 | 1876.1 万 |
| 紧急电量 | 45.4 万 kWh | 6.0 万 kWh |
| 日末 SOC 均值 | 1216（放空） | 6974（保电） |

**结论**：删 θ 使储能每晚放空到下限，第二天空仓开局、丧失隔夜缓冲，应急电暴涨约 4.6 倍、总费用 +9%。**储能的隔夜缓冲价值远大于单纯电价套利价值，θ 必须保留。**

这同时**证伪了第二问的「跨日近视」假设**（其论证只看到套利、忽略了隔夜缓冲）。论文里应把这点写成跨问结论：第二问因只有 0:00 一次决策，跨日近视近似可用；问题三引入日内滚动后，θ 必须保留。

## 四、发现 2：报童下界 q=0.8 过保守（费用高 22–28%，但注意混淆）

| | 有下界 q=0.8（A） | 无下界（B） | 变化 |
| --- | ---: | ---: | ---: |
| 问题三 M3 总费用 | 1877.6 万 | 1465.7 万 | **−22%** |
| 问题三 M3 紧急电 | 6.2 万 kWh | 18.6 万 kWh | +3 倍 |
| 问题四 C3 总费用 | 1939.9 万 | 1533.6 万 | **−21%** |
| 问题四 C3 紧急电 | 5.9 万 kWh | 16.7 万 kWh | +2.8 倍 |

**结论**：q=0.8（净负载 80% 分位）把紧急电压得很低，但代价是**计划购电严重超购 → 大量弃光 → 正常购电费虚高**，总账反而亏 20%+。紧急电与总费用是 trade-off，q=0.8 是「最保守」而非「最优」。

**建议**：正式口径应取 q≈0.5 或直接关闭（q=None），真实最优在 0 与 0.8 之间，需扫参确定。之前的 10 天小样本扫参也显示 q=0.5/0.7 的总费用低于 q=0.8。

## 五、发现 3：「更新越多越贵」的反常，与报童下界无关

两组配置下都是 **M0（只 0:00 更新）最便宜**，6:00/12:00/18:00 更新反而让总费用上升（ΔC6 恒为负）。

**这违反直觉**（更多预报信息应帮助降低成本），且**在关掉报童下界后依然存在**，说明根因不是 q=0.8 的保守性。

候选根因（需进一步排查，按概率排序）：

1. **调整费结算口径**：更新计划要付调整费（0.5·P·|G^k−G^0|），而 M0 没有调整费。若调整费本身过大，就会吃掉更新的收益。→ 建议做「调整费系数 0.5→0」的消融。
2. **wait-and-see 乐观偏差的执行层传导**：规划层的 wait-and-see 补救高估了电池对冲能力，导致计划 G 系统性偏低，更新带来的边际改善被乐观偏差掩盖。
3. **单种子噪声**：只跑了 seed=0，未做 Bootstrap，ΔC 的符号可能不稳定。

**这是问题三最需要解决的疑点**——它直接决定「哪些预报时刻值得保留」这一核心结论，当前却得出反直觉答案。

## 六、发现 4：价格信息价值随下界关闭而转正

| 配置 | 4-2 信息价值 | 4-3 信息价值 |
| --- | ---: | ---: |
| A（有下界 q=0.8） | ≈0（略负） | ≈0（略负） |
| B（无下界） | **+14.2 万** | **+16.2 万** |

**解释**：报童下界 q=0.8 已把计划购电 G 抬得足够保守（对冲充分），此时「是否提前知道精确价格」几乎没有边际价值，故信息价值≈0。关掉下界后，计划更依赖价格预测，「完美价格信息」才体现出正向经济价值（完美价格方案省 14–16 万）。

**结论**：价格信息的经济价值与「计划的保守程度」负相关——越保守（q 越高），信息越不值钱。这是一个可写的机制性结论。

---

## 七、结论与建议

1. **θ 必须保留**（最确定）：隔夜缓冲价值不可忽略，删 θ 是明确错误。
2. **报童下界不宜取 q=0.8**：过保守、总费用高 20%+。建议 q≈0.5 或关闭，并补做单变量对照消除 MPC 混淆。
3. **「更新越多越贵」是核心待解问题**：与下界无关，优先排查调整费口径（做调整费消融）。
4. **信息价值研究有价值**：可写成「信息价值随计划保守程度递减」的机制结论。
