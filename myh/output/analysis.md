> 本文件汇总「微网电力调控 C 题」问题三、问题四的数值实验结果，并对关键现象作客观分析。
> 所有结果由 `myh/src/` 下的代码运行得到，验算残差均通过（能量平衡 ~1e-12、SOC 递推 ~1e-13、无违规）。

## 四、发现 1：终端价值 θ 必须保留（θ 消融，最确定）

同情景、同随机种子，只差 θ：

| | 删 θ（跨日近视） | 含 θ |
| --- | ---: | ---: |
| M3 总费用 | 2062.3 万 | 1876.1 万 |
| 紧急电量 | 45.4 万 kWh | 6.0 万 kWh |
| 日末 SOC 均值 | 1216（放空） | 6974（保电） |

**结论**：删 θ 使储能每晚放空到下限，第二天空仓开局、丧失隔夜缓冲，应急电暴涨约 4.6 倍、总费用 +9%。**储能的隔夜缓冲价值远大于单纯电价套利价值，θ 必须保留。** 这同时证伪了第二问的「跨日近视」假设。

---

## 五、发现 2：报童下界 q=0.8 过保守（干净归因后确认）

报童下界把紧急电压低 78%，但**以计划购电严重超购为代价**（正常购电费虚高 + 大量弃光），总费用反而 **+19.5%**。

**结论**：紧急电与总费用是 trade-off。q=0.8（净负载 80% 分位）是「最保守」而非「最优」。真实最优在 0 与 0.8 之间（建议 q≈0.5 或关闭，需扫参确定）。

---

## 六、发现 3：MPC 情景数 5→50 是「净收益」

把执行层 MPC 从 5 条提到 50 条，**总费用再降 6.7%、紧急电降 33%，且无副作用**。更多情景让执行层决策更聪明（更充分对冲未来不确定性）。

**结论**：`MPC_N_SCENARIOS=50` 值得采用（代价是计算时间约 14 倍：MPC5 约 1.2s/天，MPC50 约 17s/天）。

---

## 七、发现 4：更新价值——「6:00 有害，12:00/18:00 有益」

之前笼统说「更新越多越贵」是不准确的。逐次更新拆开看（三组一致）：

| 更新 | ΔC 符号（三组） | 结论 |
| --- | --- | --- |
| 6:00（ΔC6） | 恒为负（−112.5/−25.2/−14.3 万） | **6:00 更新有害** |
| 12:00（ΔC12） | 恒为正（+25.8/+8.0/+37.6 万） | 12:00 更新有益 |
| 18:00（ΔC18） | 恒为正（+4.7/+4.0/+73.1 万） | 18:00 更新有益 |

**关键**：M0 是否最便宜，取决于 6:00 的害处是否盖过 12:00+18:00 的好处：

| 配置 | M0 − M3 | 谁更便宜 |
| --- | ---: | --- |
| A | −82 万 | M0 |
| B | −13 万 | M0 |
| C | **+96 万** | **M3（正常）** |

**结论**：真正稳定、与配置无关的现象是「**6:00 更新有害**」，而 12:00/18:00 更新始终有益。6:00 更新有害是核心待解问题（候选根因：调整费口径、wait-and-see 乐观偏差传导、单种子噪声）。

---

## 八、发现 5：价格信息价值随下界关闭而转正

| 配置 | 4-2 信息价值 | 4-3 信息价值 |
| --- | ---: | ---: |
| A（下界0.8） | ≈0 | ≈0 |
| C（无下界，MPC5） | +4.4 万 | +14.1 万 |
| B（无下界，MPC50） | +14.2 万 | +16.2 万 |

**结论**：报童下界把计划购电抬得足够保守后，「提前知道精确价格」几乎没有边际价值（信息价值≈0）。关掉下界后，计划更依赖价格预测，完美价格信息才体现正向价值。**信息价值与计划保守程度负相关**——越保守，信息越不值钱。

---

## 九、结论与建议

1. **θ 必须保留**（最确定）：隔夜缓冲价值不可忽略，删 θ 是明确错误。
2. **报童下界不宜取 q=0.8**：过保守、总费用 +19.5%。建议 q≈0.5 或关闭。
3. **MPC 情景数 5→50 是净收益**：建议 `MPC_N_SCENARIOS=50`（若算力允许）。
4. **6:00 更新有害是核心待解问题**：与下界、MPC 均无关，优先做「调整费系数 0.5→0」的消融定位。
5. **信息价值与计划保守程度负相关**：可写成机制性结论。
