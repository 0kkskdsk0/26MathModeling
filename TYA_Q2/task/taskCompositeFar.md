# Task Card

## 1. Task
- 任务目的：

1. **否证"跨日近视可行"的论证链。** `TYA_Q2\Q2Project.md` 的"模型重要假设合理性的简单论证"一节，用"日末储能的边际价值被封顶在次日凌晨低谷电价附近"来支持跨日近视假设，并在同一段落自述该论证原本计划以 $V(s)$ 扫描实验验证、现以口头论证代替。本步骤要求以 `TYA_Q2\outputs\taskComposite\` 已产出的全年滚动结果为起点，指出该论证在当前模型族内**不可检验**：充分条件左端的 $-a_{d,q}$ 是终端价值函数的切线斜率，只有先在远视模型里定义出 $V_{d+1}(s)$ 才能计算，否则该条件退化为"近视模型不为日末储能赋值"的同义反复；同时列出当前结果中与该论证预期不符的定量信号，把该章节改写成"假设的否证与远视化的动机"，并把当年被跳过的检验补做完整。
2. **建立远视模型。** 在目标函数中恢复终端价值项 $\sum_{\omega\in\Omega_d}\pi_{d,\omega}\theta_d^{\omega}$，以分段线性下界 $\theta_d^{\omega}\ge a_{d,q}S_{d,145}^{\omega}+b_{d,q}$（$q=0,\dots,Q-1$，$a_{d,q}\le0$）自下方支撑 $V_{d+1}(s)$；决策变量、物理约束、情景生成与执行层沿用 taskComposite 的定稿，使两个模型能在同一情景池、同一核权重、同一执行层下配对比较，差值只来自终端价值项。
3. **以因果方式估计终端价值函数并判定网格收敛。** $V_{d+1}(s)$ 在状态区间 $[S^{\min},S^{\max}]$ 上用采样网格上的函数值与次梯度做分段线性逼近；采样网格按**在读取消算结果之前固定**的判据逐轮加密，直到相邻网格点上价值函数估计值之差的最大值不超过给定阈值，且再加密一轮不再产生新的有效切线为止。
4. **配对对照与采纳判定。** 在同一情景池、同一核权重、同一执行层下比较近视与远视的 $C_{\mathrm{official}}$，按事先固定的相对阈值给出采纳判定；负结果如实记录，不得回调阈值或更换评分口径。

- 成功标准：

1. **否证成立且可复核。** 逐条给出该论证所依赖命题的检验结果与不可检验性的形式化理由；引用的每一项统计量都能由 `outputs/taskComposite/` 的既有文件直接复算，不得引入未落盘的中间量，也不得用新实验的结果冒充"当前结果的否定"。
2. **价值函数收敛且可追溯。** 逐轮记录网格、采样点数、各轮最大相邻差与切线集合；最终轮满足收敛判据，并通过确认加密证明切线集合不再变化。
3. **因果性。** 第 $d$ 天的切线集合与计划购电量只依赖 $j\le d$ 的观测；把第 $d$ 天及其之后的原始负载与光伏观测打乱并施加扰动后重跑，两者逐元素完全不变。
4. **对照判定。** 远视与近视在全年 334 天上的 $C_{\mathrm{official}}$ 配对比较给出明确结论；采用远视须超过事先固定的相对阈值，否则保留近视并如实记录负结果。
5. **核验。** 远视结果的 12 条形式化断言按 taskComposite 的口径全部通过，并且 $\theta\equiv0$ 时远视模型逐元素退化为近视模型。

## 5. Notes
- 易误解点：
  - 终端价值是**费用**函数，关于开局储电量单调不增且凸，因此切线斜率 $a_{d,q}\le0$ 且随 $q$ 单调不减。符号或单调性写反时，$\theta$ 取下界并不构成有效支撑，而线性规划仍会给出可行解，错误不会自行暴露。
  - 收敛判据作用在**相邻网格点上的价值函数估计值之差**上，不是作用在区间宽度上。若用区间宽度作判据，价值函数平坦处会被无限细分，而陡峭处始终过粗。
  - "次日问题"的次梯度应取共同出发点约束（所有情景从同一储电量开局）的对偶变量，而不是任一情景能量平衡约束的对偶；取错对象会得到与 $V$ 无关的斜率。
  - 估计 $V_{d+1}$ 时的期望口径必须与主模型一致，即使用同一组 $\pi_{d,\omega}$ 与同一候选池；换一套权重会让两个模型不可配对。
  - 因果性污染在残差核验里查不出来：用未来数据估计 $V_{d+1}$ 得到的仍是可行解、残差仍为零，只有扰动实验能发现。
- 可能犯错的部分：
  - 未事先固定"每轮切线集合"的构造规则（每个采样点出一条切线，还是每个区间取端点次梯度中较紧者），导致逐轮切线集合不可比、收敛判据失去意义；
  - 加密网格后沿用上一轮切线，没有重算；
  - 触及轮数或采样点上限仍未收敛时，把"未收敛"包装成"近似收敛"，或悄悄放宽 $\eta$；
  - 实际求解次数少于声明的预算却报告已完成收敛；
  - 远视递归的截断口径在见到对照结果之后被改动；
  - 在否证环节把"当前结果与论证预期不符"直接当成"论证已被证伪"，而忽略同一些现象也能被近视模型的内部一致性解释。否证的落点应是论证的**不可检验性**——左端在当前模型族内没有独立定义——而不是单个统计量的方向。
