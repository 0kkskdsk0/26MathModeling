# 一、把问题重新表述：远视与否，全部信息都在一个函数里

Bellman 方程的视角下，第 $d$ 天真正需要知道的是

$$
V_{d+1}(s) = \text{第 } d+1 \text{ 天以储能 } s \text{ 开局的最小期望费用}
$$

近视模型偷偷假设 $V_{d+1}(s) \equiv \text{常数}$，也就是"开局储能多少无所谓"。远视与否的分歧，全部浓缩在这个函数的形状里：

- 如果 $V_{d+1}(s)$ 在 $s$ 的整个取值范围内几乎是平的，近视假设成立，什么都不用改；
- 如果它有明显的斜率，那斜率的相反数 $\phi(s) = -V'_{d+1}(s)$ 就是"24:00 储能里每度电的边际价值"，把它作为终端价值项加进近视模型的目标函数，补丁就打完了。

注意这里的关键：无论探测结果如何，**都不需要建造多阶段场景树模型**。结果是平的，近视模型直接用；结果有斜率，近视模型加一个终端项即可。那个昂贵的远视模型在这条路线里从头到尾不存在，它唯一的用途是做对照组，而我们可以用便宜得多的方式获得同样的信息。

# 二、便宜的实验：用确定性单天 LP 直接探测 $V(s)$ 的形状

实验协议如下，全部成本是求解几十个小 LP。

1. 挑 3 到 5 个代表性日子：春夏秋冬各挑一个，或者更精细一点，按"光伏好、光伏差"分层各挑一两个。用附件2 的真实曲线。
2. 对每个日子，假装净负载完全已知，求解一个确定性的单天 LP，和问题一同构，只是去掉"首末储能相等"的约束，目标是最小化当天总费用含 5 倍紧急购电条款。
3. 同一个日子，把初始储能 $S_1$ 分别固定在 1200、2800、4400、6000、7600、9200、10800 这 7 个水平上，各解一次，记录最优费用，就得到 $V(s)$ 的 7 个采样点。
4. 把几个代表日的 $V(s)$ 曲线画在一起看形状。

判定标准非常直接：曲线平，近视成立；曲线有斜率，把斜率拟合成分段线性的 $\phi(S_{145})$ 加进目标函数。整个实验不涉及任何随机性、任何跨日滚动、任何场景树，一个下午就能跑完。

# 三、在跑实验之前，用纸面算术就能预判结果

我更进一步，这个实验的结果大概率已经被数据结构预定了，我们可以先算一笔账，这也帮你理解为什么我有信心说耦合弱。

**第一笔账：替代成本。** 24:00 储能里的一度电，最直接的替代品是明天凌晨按低谷价 0.42 元买进来。能不能及时买到？看吞吐：储能可用容量 9600 kWh，单时段充放上限 833 kWh，从零充到满只需要约 12 个时段也就是两小时。低谷窗口从 22:00 一直延续到次日 5:00，长达七小时。容量需求远远小于窗口供给，凌晨充电不存在排队和挤兑。所以 24:00 储能电量的边际价值被封顶在 0.42 元附近，乘以效率修正后更低。这是整个论证的支柱：跨日搬运的电，替代品极其便宜且供应充足。

**第二笔账：近视模型最可能犯的错。** 近视模型在 22:00 到 24:00 的低谷时段会倾向于把储能放空，因为放电能省 0.42 元的购电，而留着不算钱。远视的做法是留到明天早高峰 8:00 附近放，省 1.08 元。但注意，明天早高峰的电也可以今晚凌晨 0.42 元充进来补上，往返效率 0.81，折算成本约 0.52 元，仍然远低于 1.08 元。也就是说近视模型犯的错，几乎全部可以被"明天凌晨重新充电"补救，残余损失只剩效率差，每天最多几百元的量级，而日均购电费用在三四万元量级。

**第三笔账：开局空仓的风险敞口。** 唯一需要认真对待的情形：明天 0:00 以 $S_1 = 1200$ 开局，储能贴底，前几个时段没有放电缓冲，如果凌晨实际净负载超过计划，只能紧急购电。但凌晨电价 0.42 元，紧急购电 5 倍也才 2.1 元，是全天最便宜的紧急购电时段；而且计划购电无功率上限、直达负载，凌晨时段的裕度可以靠多买计划电直接堆出来，不需要储能兜底。所以这个敞口可以用"凌晨时段计划裕度略加大"来廉价关闭。

三笔账指向同一个预判：$V(s)$ 会很平。但这仍然是预判，第二节的实验才是证据。我列这笔账的目的，是让你理解实验在验证什么、以及如果结果相反该怀疑什么。

# 四、实验的一个盲区，以及怎么补

确定性探测有一个已知盲区：它量不出储能在**日内不确定性下的保险价值**。开局多 2000 度电，在确定性世界里只值 0.42 元一度，但在随机世界里它是防 5 倍电价的缓冲垫，尤其在白天高价时段。不过注意，这个盲区伤害的是"日内初始储能"的价值评估，而我们的问题恰恰是"跨日传递"的储能价值，传递的目的地是凌晨，全天电价最低、紧急购电最便宜、计划购电最自由的时段。盲区与问题错开，所以影响小。

如果你想把这个盲区也补上，升级路径很便宜：把探测里的确定性 LP 换成单天的场景随机规划模型，也就是把近视主模型本身拿来，固定不同的 $S_1$ 各跑一遍，比较含紧急购电的总期望费用。这仍然只是"同一个近视模型跑七八遍"，不需要造任何新模型。我的建议是把这作为探测的标准形式，反正主模型迟早要建，建好之后这个实验就是零边际成本。

# 五、总结这条工作流

1. 先用纸面算术形成预判：跨日价值被封顶在低谷价，预判耦合弱；
2. 建近视主模型时，把终端价值项 $\phi(S_{145})$ 作为标准接口留在目标函数里，初值设为零；
3. 用"主模型加固定 $S_1$ 扫描"的实验探测 $V(s)$ 形状，平了就把接口留空，斜了就把斜率填进去；
4. 最后全年回测时，用 $\phi = 0$ 和探测得到的 $\phi$ 各跑一遍 334 天，总费用差异就是这组假设的最终裁决，顺便成为论文模型检验节的素材。

这样整个"远视问题"被拆解成一个扫描实验加一个接口设计，远视模型自始至终不需要被建造。
