# 优秀论文写法模式库

只有用户明确要求“参考优秀论文”“对照优秀论文写法”“提炼加分项”“审稿”“润色”等写作模式建议时，才使用本参考。

普通 Markdown 转 LaTeX、格式排版或编译修复时，不要加载或应用本参考。在仅格式转换模式下，优秀论文写法不能影响用户原文措辞、段落结构、结论或论证顺序。

这些内容是写法模式，不是正文来源。不要复制优秀论文的措辞或结果。

## 如何使用这个库

1. 先识别题型：A 题通常偏优化，B 题通常偏物理/工程机理，C 题通常偏数据分析/统计/机器学习，D/E 题通常更开放或交叉。
2. 选择同题型、近年份的 2-4 张卡片阅读。
3. 只提炼写法动作，不提取论文内容。
4. 将写法动作迁移到用户自己的模型、数据和结果上。

如果某张卡片只有元数据，应明确说明该论文还需要 OCR 或精读后才能作为详细写法参考。

## 跨题型高分写法

- 摘要用紧凑顺序交代模型、算法、结果和验证证据。
- 问题分析在公式出现前解释方法为什么适合当前数据或机理。
- 每个小问结尾有简短结论，并能自然承接下一问。
- 重要公式由推理引出，而不是孤立地丢出一个方程。
- 图表作为论断证据使用，正文解释图表证明了什么。
- 验证方式与模型类型匹配：优化问题看敏感性，预测问题看残差/误差，物理问题看机理一致性，机器学习较重的问题看稳健性或消融。
- 模型评价指出真实限制，并给出具体改进方向。

## A 题：优化类论文

可借鉴写法：

- 从场景约束出发，转化为决策变量、目标函数和可行域。
- 先建立基准模型，再逐步增加约束或维度。
- 直接优化维度过高时，使用分解思路。
- 对关键参数和搜索粒度做敏感性分析。
- 关键最优解尽量使用第二算法或局部验证增强可信度。

写法模板：

```tex
问题一首先需要在【约束】下确定【决策变量】。为此，本文以【目标】为优化目标，
将【关键条件】转化为约束组，构建如式~\cref{eq:...} 所示的优化模型。
在求解过程中，先通过【粗搜索/解析化简】确定可行区域，再采用【算法】进行局部寻优。
```

## B 题：物理或工程机理论文

可借鉴写法：

- 拟合或数值求解前，先解释物理机制。
- 清楚说明近似条件，不把近似写成事实。
- 长推导放入附录，正文聚焦控制方程和核心关系。
- 用已知物理范围、重复测量条件或边界情形做一致性检查。
- 如果多个机理都可能成立，应明确比较。

写法模板：

```tex
由【物理原理】可知，【变量】与【观测量】之间存在【关系】。考虑到题目中【条件】，
本文将【因素】近似为【处理方式】，从而得到【核心方程】。该方程刻画了【机制解释】，
并为后续参数反演提供依据。
```

## C 题：数据分析类论文

可借鉴写法：

- 把预处理交代清楚：缺失值、异常值、特征构造、归一化、分组。
- 解释为什么观测变量能够预测或区分目标变量。
- 选择与任务相匹配的评价指标。
- 避免堆模型名。每个模型必须有不同角色。
- 用可解释性分析或特征重要性支撑结论。

写法模板：

```tex
附件数据包含【数据特征】，其中【变量】与【目标】表现出【趋势/差异】。因此本文先进行
【预处理】，再构建【模型】刻画二者关系，并使用【指标】评价预测/分类效果。
```

## D/E 题：开放或交叉类论文

可借鉴写法：

- 讨论政策、方案或建议前，先定义决策准则。
- 问题范围较广时，使用层次化指标体系。
- 区分模型输出和政策解释。
- 通过情景分析说明不同假设下的适用性。

## 反面模式

- 只写“首先对数据进行了预处理”，却不说明数据有什么问题、如何处理。
- 只写“结果如图所示”，却不解释图表。
- 摘要中反复使用同一种“针对问题 X”的句式。
- 只写算法名称，不定义目标、变量、约束或评价指标。
- 在正文中写软件操作过程，例如文件路径、函数调用、编译说明或调试日志。
- 模型评价过度拔高，给出没有条件限制的大话。
