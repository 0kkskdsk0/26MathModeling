# 按题型整理的论文写法模式

当用户要求按题型快速给写作建议时，先读本文件，再按需要打开具体优秀论文卡片。

## A 题：优化 / 调度 / 策略

推荐论文节奏：

1. 将场景重述为有约束的决策问题。
2. 定义变量、目标函数和可行域。
3. 建立基准模型或简化模型。
4. 加入题目特定约束或更高维度。
5. 使用有理由的算法求解。
6. 用敏感性、搜索粒度或跨算法比较做验证。

高价值审稿问题：

- 草稿是否在命名算法前先定义了目标函数？
- 约束是否完整，并且已经数学化表达？
- 后续模型是否扩展或修正了前面的模型？
- 最优解是否有敏感性分析或对比验证支撑？

## B 题：物理 / 工程 / 测量

推荐论文节奏：

1. 解释机理或物理定律。
2. 说明受控近似。
3. 推导控制关系。
4. 估计或反演参数。
5. 与物理范围、重复数据或替代机理比较。

高价值审稿问题：

- 每个公式背后是否有原理支撑？
- 假设是否具有物理意义，而不是泛泛假设？
- 图片是否服务机理解释，而不只是展示数据？
- 长推导是否放入附录，正文是否保留关键方程？

## C 题：数据分析 / 统计 / 机器学习

推荐论文节奏：

1. 说明数据质量和预处理决策。
2. 解释变量与目标之间的关系。
3. 根据数据结构选择模型。
4. 使用符合任务目标的指标评价。
5. 解释结果，并连接到题目决策。

高价值审稿问题：

- 预处理是否说明了问题、方法、参数、保留特征和处理效果？
- 每个模型的角色是否清楚？
- 指标是否真正回答了题目要求？
- 结果是否被解释，而不是只做排序？

## D/E 题：开放 / 交叉 / 政策导向

推荐论文节奏：

1. 定义评价准则和决策范围。
2. 建立指标体系或情景框架。
3. 谨慎地把定性因素转化为可度量变量。
4. 比较不同情景或策略。
5. 给出与模型输出绑定的建议。

高价值审稿问题：

- 主观评价准则是否明确？
- 论文是否区分模型输出和建议？
- 情景假设是否可见？
- 局限性是否具体？
